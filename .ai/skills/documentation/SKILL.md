# Documentation — frappe_docker

VitePress static site built from `docs/` markdown files.

## Structure

```
docs/
├── .vitepress/config.mts  # Site config (nav, theme, plugins)
├── index.md               # Home page (layout: home)
├── getting-started.md     # Long-form landing guide
├── 01-getting-started/    # Setup docs (numbered sections)
├── 02-setup/
├── 03-production/
├── 04-operations/
├── 05-development/
├── 06-migration/
├── 07-troubleshooting/
├── 08-reference/
├── 09-concepts/
└── images/                # Screenshots, diagrams
```

## Conventions

### Frontmatter
```yaml
---
title: Short Title for Sidebar
---
```
Every `.md` file needs frontmatter with a `title` field for sidebar display.

### Images
- Store in `docs/images/`
- Reference with relative path: `![Alt](../images/file.png)`
- Uses the `../images/` pattern from any subdirectory

### Sidebar
- Auto-generated by `vitepress-sidebar` plugin
- Controlled by folder structure + index.md files
- Config in `.vitepress/config.mts`:

```ts
import { withSidebar } from "vitepress-sidebar";
const vitePressSidebarOptions = {
  documentRootPath: ".",
  useTitleFromFrontmatter: true,
  useFolderTitleFromIndexFile: true,
};
```

### Building
```bash
cd docs
npm install    # pnpm install also works (pnpm-lock.yaml exists)
npm run docs:build  # outputs to docs/.vitepress/dist/
```

## VitePress Extensions
GitHub-flavored Markdown is supported. Avoid complex VitePress-only syntax to maintain GitHub compatibility. Simple tables, code blocks, and lists are safe.

## Adding a New Page
1. Create `docs/<section>/<filename>.md` with frontmatter
2. Sidebar auto-detects via folder structure
3. Link from relevant pages or nav in `.vitepress/config.mts`
